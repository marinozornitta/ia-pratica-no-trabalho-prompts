Este aplicativo (bot de automacao do canal @iapraticanotrabalho) usa a YouTube Data API v3 apenas para publicar, no proprio canal do responsavel pelo projeto, os videos gerados automaticamente pela pipeline de conteudo.

O aplicativo nao coleta, armazena ou compartilha dados de terceiros. Ele nao acessa dados de outros canais, inscritos ou espectadores. O unico escopo solicitado e youtube.upload, usado exclusivamente para o envio de videos.
